# AuthenText – AI vs Human Text Classification

## Overview
A Deep Learning and Natural Language Processing project for distinguishing between AI-generated and human-written text.

## Dataset
- AI vs Human Text Dataset
- Source: [Kaggle](https://www.kaggle.com/datasets/shanegerami/ai-vs-human-text)
- Binary classification: Human (0) and AI (1).

## Models
- Artificial Neural Network (ANN)
- Long Short-Term Memory (LSTM)

## Technologies
- Python
- Pandas and NumPy
- TensorFlow / Keras
- NLTK
- Gensim (Word2Vec)
- Matplotlib and Seaborn

## Methodology
1. Dataset loading and exploration.
2. Text preprocessing and cleaning.
3. Word2Vec feature extraction.
4. Training and evaluation of ANN and LSTM models.
5. Comparison of model performance.

## Reported Results
The original project reports approximately 87% test accuracy for its LSTM model. This result has not yet been independently reproduced.
